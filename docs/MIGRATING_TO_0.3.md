# Content Generation Modules 0.3 guide

The helper's 0.3 contract added scan-first writing and target-specific brand/visual direction. A later 0.3.x revision strengthened prompt, asset-hash, and private-holdout records.

## Contract change

The migration preserves semantic headings and short, meaningful anchors while asking the reviewer to check the heading-and-bold scan as a second story. Narrative assets require exact copy, accessibility notes, crop guidance, review decisions, and a verifiable hash.

## Apply to this repository

The target adapter keeps jev-classifier's research-paper palette and avoids copying another repository's visual identity. The two committed images have records and hashes. Their prompt notes are reconstructed from delivered assets because the original prompts were not retained.

The target is pinned to CGM 0.4.0. Use [BRAND_DIRECTION.md](BRAND_DIRECTION.md), [IMAGE_GUIDE.md](IMAGE_GUIDE.md), and [the asset manifest](../.content-system/asset-manifest.json) for current adapter decisions.
